# Contoh-d-Besto

Website d’Besto — Jagonya Rasa, brand fried chicken dan burger PT Evalinda Berkah Mandiri.

## Isi website
- Hero dan pengenalan merek.
- Kategori menu dan dialog detail produk.
- Cerita perusahaan, pesanan acara, dan kemitraan.
- FAQ, formulir pesan WhatsApp, serta tombol chat.
- Tampilan responsif untuk layar desktop dan ponsel.

## Menjalankan secara lokal

Tidak memerlukan instalasi dependensi. Jalankan dari direktori proyek:

```bash
python3 -m http.server 8000 --directory dist
```

Buka http://localhost:8000.

## Struktur

- `dist/index.html`: struktur dan konten halaman.
- `dist/style.css`: tampilan dan tata letak responsif.
- `dist/app.js`: filter menu, dialog, navigasi, dan penyusunan pesan WhatsApp.
- `dist/assets/`: gambar referensi merek dan dokumentasi produk perusahaan.

## Catatan konten

Versi konsep berdasarkan Brand Guidelines d’Besto 2026 dan profil perusahaan yang disediakan. Harga, ketersediaan menu, ketentuan kemitraan, dan nomor kontak perlu diperbarui sesuai data perusahaan yang berlaku. Nomor WhatsApp saat ini: 0812 2345 7871 dari Company Profile.

Foto dan identitas merek tetap merupakan aset pemiliknya; repositori ini tidak memberikan lisensi penggunaan ulang aset merek.
